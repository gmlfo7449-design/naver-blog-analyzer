# 블로그 발행 분석기 (네이버 블로그 RSS)

네이버 블로그 ID를 넣으면 최근 공개 글(최대 50개)의 발행 패턴을 분석합니다. 최대 5개 블로그를 나란히 비교할 수 있습니다.

## 실행
```
node server.js      # http://localhost:3000  (Node 18 이상, 설치할 패키지 없음)
```

## 배포 (Vercel)
폴더를 그대로 올리면 됩니다. `public/`은 정적 페이지, `api/rss.js`는 서버리스 함수(`/api/rss?id=블로그ID`)로 동작합니다.

## 구조
- `api/rss.js`: `rss.blog.naver.com/{id}.xml`을 서버에서 가져와 JSON으로 변환합니다. 네이버 RSS에 CORS 헤더가 없어 브라우저에서는 직접 부를 수 없습니다. 결과는 10분 동안 캐시됩니다.
- `public/index.html`: 분석 화면입니다(Chart.js).
- `server.js`: 로컬 실행용입니다.

## RSS로 확인한 데이터 범위
| 있음 | 없음 |
|---|---|
| 제목, 링크, 카테고리, 발행일시, 태그, 본문 앞부분(약 230~380자), 대표 이미지 | 조회수, 공감 수, 댓글 수, 본문 전체, 검색 순위, 이웃 수 |

- 최근 공개 글 **50개**까지만 들어옵니다.
- 없는 ID여도 HTTP 200에 빈 RSS가 돌아오므로, 제목과 글이 모두 없으면 "찾을 수 없음"으로 처리합니다.
